# xhs-review

一个账号唯一可信的「什么有用」来源，就是它自己的数据。所有攻略里的规则，包括这个 pack 里的，都只是先验。

```bash
xhs review notes.csv          # 表格输出 + 诊断
xhs review notes.csv --md     # Markdown，追加到 $XHS_HOME/review.md
```

## 拿数据

从创作中心的「数据中心 → 笔记数据」拿，每篇一行。本人截图给你、或者本人在场时你在他已登录的浏览器里读。**不替本人登录，不用第三方数据工具抓。**

能拿到的列都要（表头中英文都认）：

```
日期,标题,曝光,观看,平均观看时长,点赞,收藏,评论,分享,涨粉
```

至少要最近 6 篇，越多越好；只有这一篇也能跑，但只能看数，没法比。

## 为什么只和自己比

网上流传的「点击率低于 5% 就是差」这种绝对线没有出处，不同领域差得很远。这里所有判断都是和**本账号最近笔记的中位数**比。

## 漏斗，从前往后找第一个掉下去的

```
曝光  →  观看（点击率 = 观看 / 曝光）  →  留下（收藏率、平均观看时长）  →  关注（涨粉 / 观看）
分发问题       封面 / 标题问题                   内容兑现问题                         主页问题
```

| 现象（和中位数比） | 是哪里的问题 | 下一步 |
| --- | --- | --- |
| 曝光不到一半 | 分发。先看这篇有没有违规 / 限流提示，再看话题和标题里的搜索词 | 查 `xhs check` 有没有漏掉的 WARN |
| 曝光正常，点击率低 | 双列流那一秒：封面大字和标题 | 下一篇换句式；`xhs-viral` 看同领域封面 |
| 点进来了，收藏率和观看时长都低 | 内容没兑现封面：第 2 张卡没给答案，或者能复制的东西藏在后面 | 下一篇第 2 张就兑现 |
| 观看高、涨粉低 | **不是这篇失败了，是主页没接住** | 去 `xhs-profile` |
| 评论率是中位数两倍以上 | 评论区有下一篇 | 去 `xhs-reply` |
| 观看两倍以上、收藏率也不低 | 信号 | 记下选题类型和句式，下周复用一次 |

最先掉下去的那一段决定一切，它后面的都是下游，别在下游上花力气。

## 对照「本篇在测什么」

每篇发的时候都写了在测什么（`xhs log list` 能看到）。复盘的结论要回答它：测到了吗、方向对吗。没测出来也是结论。

## 也看看别人

本人要求复盘时也看同类博主怎么做。数据看完，挑一两个这周同题或同句式的对标笔记，用 `xhs-viral` 的方法看一眼：他们的封面、第 2 张、收藏/点赞比和你的差在哪。只记差别，不抄。

## 结论怎么写

- 10 篇以内：只说「这篇哪一段掉了」，不说「X 类选题不行」。
- 10-30 篇：写成「下 5 篇验证 X」，不写成「X 有效」。
- 30 篇以上：可以下结论，附证据和 n。
- 发布时间**最后才看**，而且只在其他都看不出东西时看。它几乎从来不是原因，却是大家最想怪的。

## 输出

```
复盘  ·  6 篇  ·  中位数：曝光 1.1万 / 观看 1250 / 点击率 12.0% / 收藏率 16.0% / 涨粉率 1.2%

    倍数    曝光  点击率  收藏率  涨粉率 句式            标题
    3.8x   3.0万   16.0%   18.8%    0.5% #9 一张图讲清   一张图看懂MCP到底是什么
    ...

诊断
  一张图看懂MCP到底是什么
    - 主页：看的人多、关注的少。这篇没失败，是主页没接住，去 xhs-profile。
  AI编程入门的一些思考
    - 封面 / 标题：曝光正常，点击率只有中位数的 35%。

结论（6 篇，只看单篇）
  1. 「一张图」那篇的流量没变成关注：先修主页，再谈多写。
  2. 「一些思考」这类标题点击率掉一半：不再用没有搜索词的标题。
下 5 篇验证：#1 直接抄 + 第 2 张就给可复制内容，收藏率能否稳定在中位数以上。
```

结论交给 `xhs-plan`（下周按证据排），主页问题交给 `xhs-profile`，评论区的问题交给 `xhs-reply`。追加一份到 `$XHS_HOME/review.md`，下次复盘先读它。
