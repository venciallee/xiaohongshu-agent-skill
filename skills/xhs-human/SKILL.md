# xhs-human

```bash
xhs human draft.txt --report -o clean.txt   # 改能安全改的，标出要你改的
xhs detect draft.txt                        # 五项自检
xhs detect draft.txt clean.txt              # 前后对比
```

## 读 / 写

| | 文件 | 用途 |
| --- | --- | --- |
| 读 | 草稿文本 | 正文、卡片文字、回复草稿都行 |
| 读 | 内置 `slop.json` | 词库（`$XHS_HOME/data/slop.json` 可覆盖） |
| 写 | 改后的文本 | `-o clean.txt` |

词库在 `slop.json`（`xhs defaults --dump ~/.xiaohongshu/data` 导出来改）。用户常用、觉得不算 AI 腔的词，直接从文件里删掉那一条。

## 先说清楚这是什么

这是**读者视角**的检查：小红书读者一眼觉得「这是模板 / 这是 AI 写的」就划走，这个工具量的是那些让人觉得像模板的东西。

它**不是**平台的 AI 识别，也**不是**用来绕过它的。平台规则要求 AI 生成或润色过的内容主动声明，未声明的会被识别、加标、限流；《人工智能生成合成内容标识办法》也禁止删除或隐匿 AI 标识。所以：

- 这个工具不碰任何不可见字符、元数据或隐式标识。
- 分数再高，用了 AI 就照样在 App 里勾选 AI 声明。
- 不要对用户说「这下检测不出来了」。目标是读着像人话，不是骗过谁。

## 自动改的（改完句子一定还通顺）

1. **排版**：破折号「——」改逗号；汉字后面的半角标点改全角；去掉 `**加粗**` 和 `# 标题` 的符号（小红书不渲染，会原样显示）。
2. **改写**：开头的「在当今……时代」「随着……的发展」删掉；「进行优化」→「优化」，「能够」→「能」，「通过使用」→「用」。
3. **填充语**：「值得注意的是」「众所周知」「毋庸置疑」「综上所述」这类删了不影响意思的，连同后面的逗号一起删。

代码块、网址、`{{占位符}}` 不会被动。

## 只标记、不改的（你来重写）

中文换词要看整句，脚本硬换只会把句子弄坏。这些会列出来：

- **黑话**：赋能、抓手、闭环、底层逻辑、链路……对读者说人话。
- **空话**：至关重要、不可或缺、显著提升（给数字）、强大的（强在哪）……
- **模板感**：保姆级、手把手、干货满满、建议收藏、一文读懂……
- **网感套话**：宝子们、家人们、绝绝子、天花板、封神……人设不符就别用。
- **句式**：「不是 A，而是 B」「不仅……更……」「这不仅仅是……更是……」、设问自答、排比三连、「首先……其次……最后」、emoji 开头的列表、「小标题：内容」堆叠、开场白、身份句、「希望对你有帮助」式结尾、句子长度太均匀。

「不是 A 而是 B」是中文 AI 腔里最典型的一个：先立一个靶子再推倒。直接说 B。

## 五项自检

| 项 | 量什么 | 像模板的样子 |
| --- | --- | --- |
| 句长起伏 | 句子长度的变化 | 每句都差不多长 |
| 具体度 | 每百字的数字、工具名、命令 | 全是抽象名词 |
| 套话密度 | 每百字的词库命中 | 满篇「赋能」「至关重要」 |
| 格式指纹 | 破折号、Markdown、emoji 列表、连续感叹号 | 排得太「整齐」 |
| 口语感 | 我 / 你、口语词、句式套路 | 没有人在说话 |

总分 = 平均分 × 0.6 + 最低一项 × 0.4（一个信号就够读者起疑）。PASS 要总分 ≥70 且没有一项低于 55。这五项都是本地启发式，没有在真实小红书数据上验证过，当参考用。

## 顺序

1. `xhs human draft.txt --report -o clean.txt`
2. 读第 4、5 部分的标记，逐条手改 clean.txt。
3. `xhs detect draft.txt clean.txt` 看前后对比。
4. 没到 PASS，就改最弱那一项，再跑。两轮正常；五轮说明稿子是套模板写的，换一稿。
5. 给用户看改后的文字和分数，不要只给分数。
