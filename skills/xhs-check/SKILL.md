# xhs-check

```bash
xhs check post.json
xhs check post.json --keywords "搜索词1,搜索词2"   # 覆盖 post.json 里的 keywords
xhs check post.json --json
```

## 读 / 写

| | 文件 | 用途 |
| --- | --- | --- |
| 读 | `post.json` | 要检查的笔记 |
| 读 | `house.json` | 账号规则：卡片数、话题数、身份句、第一人称标记、卡片禁用词 |
| 读 | `log.jsonl` | 和最近 5 篇比同质化 |
| 读 | 内置 `platform.json` | 平台限制和风险词（`$XHS_HOME/data/` 可覆盖） |

只有一个问题它回答：这篇可以交给用户去 App 里发了吗。READY 是可以；REVIEW 是有 WARN 要当面决定；FIX 是有 FAIL 必须改。

## 它先画一个框

```
  双列流里大概长这样（示意，字号按缩略图估算）
  +------------------------+
  |   改好了≠测过了        |
  |  一段话，让 Claude     |
  |  Code 改完先跑测试     |
  +------------------------+
    AI说改好了却没跑测试？
    抄这段
```

先看这个框，再看下面的清单。读者在双列流里就看到这么多：封面大字和标题的前一两行。字数合规但这个框里没东西，一样没人点。

## 查什么

| 类 | 项 | 级别 | 依据 |
| --- | --- | --- | --- |
| 平台 | 标题 ≤20 字、正文 ≤1000 字、图片 ≤18 张 | FAIL | 平台限制（`platform.json`，核实日期写在文件里） |
| 平台 | AI 声明 | FAIL 如果没写 | 平台 2026-04-27 AI 治理规则：AI 生成或润色的内容主动声明；2026-02-12 公告：未主动标识的会被加标并限制分发；《人工智能生成合成内容标识办法》第十条 |
| 平台 | Markdown 残留 | WARN | 小红书正文不渲染 `**` 和 `#`，会原样显示 |
| 风险 | 手机号、「私信领取」「评论扣 1 领」 | FAIL | 交易导流 / 站外导流规则 |
| 风险 | 微信 / vx / 网址 / 邮箱 / 站外平台名 | WARN | 同上。提到产品名可以忽略，留联系方式不行 |
| 风险 | 「点赞过 100 更新」「转发抽奖」 | FAIL | 诱导互动 |
| 风险 | 求赞、一键三连、关注不迷路 | WARN | 诱导互动 |
| 风险 | 极限词（最强、全网最、第一……）、标题党（震惊、封神、程序员要失业） | WARN | 「夸大其词」是社区规则监测项 |
| 账号 | 卡片数、话题数、封面字数、卡片字数 | WARN | `house.json` |
| 账号 | 自我介绍 / 身份句 | `house.json` 的 `identity_sentence`（默认 WARN，可设 FAIL） | 账号规则 |
| 账号 | 「我试过」「实测」类句子没确认 | WARN，并单独列出 | 第一人称经历要用户点头（`first_person_markers` 可改） |
| 账号 | 卡片上有来源、口径、免责 | WARN | `card_forbidden`：挪到置顶评论 |
| 账号 | 缺 `require_fields` 里的字段（默认洞察句） | WARN | 没有它复盘不知道在验证什么 |
| 账号 | 和最近 5 篇句式重复 3 次以上、封面大字重复 | WARN | 平台把「套模板批量生产同质化内容」列为 AI 低质 |

## 怎么处理结果

1. **FAIL 全部改掉**，改完重跑。
2. **每个 WARN 当着用户的面决定**：改，或者不改并说出为什么（例如「微信」是在讲微信小程序开发，不是联系方式）。不要悄悄放过一个 WARN。
3. **第一人称句**：逐句问用户「这是你的真实经历吗」。是，原句写进 `first_person_confirmed`；不是，改成机制说法（「我试过之后发现 X」→「X 的原因是 Y」）。
4. READY 之后再出图、交付。

## 交给用户时附上发布清单

```
发布清单（你在 App 里做）
[ ] 上传卡片，按 card-01、card-02… 顺序
[ ] 选标题（3 选 1），粘贴正文
[ ] 用 # 从联想里选话题（纯文本 # 不一定变成话题）
[ ] 打开 AI 声明
[ ] 发布
[ ] 发置顶评论：来源和说明，然后置顶
[ ] 回我一句「发了」，我记下来，72 小时后复盘
```

## 它不做什么

- 不查平台的实时规则。规则会变：`platform.json` 写着核实日期，和 App 提示冲突时以 App 为准，然后改文件。
- 不判断内容对不对。事实查证在 `xhs-note` 的查证一步。
- 不登录、不上传、不发布。
