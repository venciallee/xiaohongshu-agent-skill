# audience.md

读者是谁、在搜什么、在问什么。由 `xhs-audience` 生成和更新，`xhs-topic` 打「有人搜」那一项、`xhs-note` 写标题和开头时都读它。

每一行都写来源和日期。没有来源的判断不写进来。
